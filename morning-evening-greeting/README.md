# Morning or Evening Greeting

A simple React project demonstrating conditional rendering.

## How it works
- Gets the current hour using `new Date().getHours()`.
- Displays **Good Morning** when the hour is less than 12.
- Otherwise, displays **Good Evening**.

## Run locally
1. Install Node.js.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
